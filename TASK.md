# Assignment: AI-Powered Feature for a Cloud Communication Platform

## Overview

No predefined feature is given. Explore, define, and prototype an AI-powered feature relevant to a cloud communication platform.

## Background

We build cloud-based communication systems (voice, call centers, messaging) using technologies such as **FreeSWITCH** and **Asterisk**.

## Objective

Design and prototype a small AI-driven feature that could realistically be part of a communication platform.

## Time Constraint

Limit work to **60–90 minutes**.

> The focus is on approach and thinking, not completeness.

---

## Your Task

### 1. Problem Discovery

Identify a real problem or opportunity in one of these areas:

- Call centers
- Customer support
- Voice systems
- Agent workflows
- Monitoring and analytics

You may:

- Use your own ideas
- Use AI tools to explore ideas
- Simulate user or stakeholder conversations using AI

### 2. Feature Definition

Define your proposed solution:

- What is the feature?
- Who is it for?
- What problem does it solve?
- Why is it valuable?

### 3. AI Interaction

Use AI tools to:

- Explore the problem space
- Refine your idea
- Help design the solution

Document how you used AI during this process.

### 4. Minimal Prototype

Build a small prototype that demonstrates your idea. It can be:

- A backend endpoint
- A script
- A simple UI
- A simulated flow

The goal is to demonstrate how the feature works, not to build a full product.

### 5. Architecture

Briefly explain:

- How the feature would integrate into a real system
- Where it fits in the flow (real-time, asynchronous, batch)
- Basic scalability considerations

### 6. Validation

Explain:

- How you would measure success
- What metrics you would track
- Potential risks or failure cases

---

## Deliverables

### 1. Prototype

- Source code or working demo
- Instructions for running the project (or a Dockerfile)

### 2. Report

A short report covering:

| Section | Contents |
| --- | --- |
| **Problem Exploration** | How you identified the problem |
| **AI Usage** | Which tools you used; how you used them |
| **Prompts and Iterations** | Example prompts; what worked and what did not; how you improved results |
| **Decision Making** | Why you chose this idea |
| **Prototype Explanation** | What you implemented; what is real vs. simulated |
| **Reflection** | What you would improve with more time; limitations or risks |
